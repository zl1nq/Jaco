先确定用户指定的审查范围，读取相关实现、调用方和已有测试。用具体执行路径验证问题是否可达。

涉及异常处理、资源或共享状态时，通过 skill_read 读取 references/checklist.md，再检查相关分支。

先报告可证实的问题，每项给出文件位置、触发条件、影响和修复建议。把确定的问题与需要进一步验证的疑点区分开；没有发现问题时明确说明，并列出尚未验证的范围。

本技能交付审查报告。用户另行要求修复时，再按当前模式和工具授权实施修改。
