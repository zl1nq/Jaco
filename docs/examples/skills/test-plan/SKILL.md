description: 根据具体变更和现有测试设计回归及人工验收方案，适用于测试规划、验收清单和覆盖缺口分析。
---

读取变更和最相关的已有测试，确认外部可观察的行为、失败路径及与其他功能的交互。

按风险选择需要验证的场景，为每项说明准备条件、操作、预期结果和自动或人工验证方式。通过 skill_read 读取 templates/acceptance.md，按任务需要组织交付。

区分已有测试证据、建议新增的自动回归和必须人工验证的体验。只设计方案时，不把尚未执行的测试写为通过。

如用户要求执行验证，沿用项目已有命令和当前授权；计划模式下先提交方案，等待专用批准。
