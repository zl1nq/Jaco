# 交互与会话

[返回文档目录](README.md) · [项目首页](../README.md)

## 功能概览

- **终端交互**：流式输出、等待动画、Markdown 渲染、代码高亮与中文表格对齐。
- **工具调用**：读写文件、浏览目录、搜索代码、执行命令、检索归档与委派子任务。
- **权限控制**：只读工具自动放行，写入、命令执行和子任务需确认；支持按工具在当前会话内放行。
- **会话管理**：自动保存和恢复会话，支持查看历史、切换会话与中断当前任务。
- **上下文管理**：大工具输出自动归档，长对话分层压缩，保留可检索的原始历史。

## 任务示例

进入交互界面后，直接输入任务，例如：

```text
帮我梳理这个项目的结构，并说明入口和核心模块。
检查配置加载逻辑，找出可能导致启动失败的原因。
帮我修改这个方法，并运行相关测试。
```

主输入框支持多行：**Enter 发送，Shift+Enter 换行**，同时保留 Alt+Enter 兼容。支持整段粘贴的终端会将多行内容留在同一个编辑框中，粘贴完成后再按 Enter 发送一次；CRLF、CR、LF 统一为换行，保留段落内的空行。输入中的引号或反斜杠不会触发 Shell 续行规则。整段多行内容即使包含 `/help` 等文本，也作为一条提示词发送，不逐行执行命令。

Windows 原生控制台使用专门的 JLine JNI 适配器，在原生按键事件的 Shift 信息丢失之前将 Shift+Enter 转成换行序列；不需要另外配置按键映射。启动横幅显示“Windows 原生按键 · Shift+Enter 换行”表示该入口已启用，主输入框及提问回答框共用同一输入处理。原生入口不可用时会回退默认终端并在日志记录原因，Windows 默认入口会明确显示适配未启用。

其他终端支持 CSI-u 和 xterm modifyOtherKeys 格式。若终端在送入应用前就把 Shift+Enter 与 Enter 合并为同一回车字符，应用无法恢复修饰键；可使用 Alt+Enter、配置 Shift+Enter 发送 `\u001b[13;2u`，或使用下述 `/paste` 模式。IDEA 的普通 Run 控制台与 Terminal 面板是不同的输入入口，组合键测试建议在 PowerShell 控制台或 IDEA 的 **Terminal** 面板运行 JAR。修改源码后需要重新构建并重启 JAR；旧 JAR 不会自动加载新实现。

如果终端把粘贴内容逐行提交，先在 **JACO 内**输入 `/paste` 并回车，然后粘贴全部内容，最后独立一行输入 `/end`。收集期间不发送模型请求、不执行粘贴内容中的命令；结束后整段内容回到编辑框，确认后再按 Enter 发送。Ctrl+C 或输入关闭取消本次收集。兼容模式中的独立 `/end` 行为结束标记，需要包含这个字面行时使用普通整段粘贴。

## 命令与快捷键

| 命令 / 快捷键 | 作用 |
| --- | --- |
| `Enter` / `Shift+Enter` | 主输入框发送 / 插入换行；提问回答框同样支持，兼容 Alt+Enter |
| `/paste` | 多行粘贴兼容模式，独立一行 `/end` 结束并放回编辑框，回车确认发送 |
| `/help` | 显示可用命令 |
| `/new` | 创建新会话，清空当前上下文与权限放行记录 |
| `/sessions` | 按新到旧列出会话 ID、标题和消息数，`*` 标记当前会话 |
| `/subagents [完整任务 ID]` | 查看当前会话的子任务状态；指定 ID 查看已退出任务的结果和用量 |
| `/subagents cancel <完整任务 ID>` | 请求取消指定子任务，用查询确认实际退出 |
| `/cancel` | 运行期间中断当前轮，与 Ctrl+C 相同；空闲时提示没有运行中的轮次 |
| `/switch <会话 ID>` | 切换会话并清空权限放行记录，支持唯一 ID 前缀 |
| `/delete <会话 ID>` | 删除历史会话及归档，支持唯一 ID 前缀；需确认，不能删除当前会话 |
| `/memory` | 查看用户画像、条目 ID、类别和作用范围 |
| `/memory forget <ID>` | 删除指定画像条目，使用完整 ID |
| `/memory clear` | 确认后清空全部画像，包含所有项目 |
| `/memory off` / `/memory on` | 关闭 / 开启自动记忆与画像加载，设置随画像持久保存 |
| `/exit` 或 `Ctrl+D` | 退出 |
| `Ctrl+C` | 中断当前轮：取消模型流、终止命令子进程、拒绝待确认操作；已生成内容保留进会话 |

启动时自动恢复最近一次会话；没有历史会话时创建新会话。

模型或子 agent 运行期间，可直接输入 `/subagents [完整任务 ID]`、`/help`、`/cancel` 并回车执行。查询不会中断任务，也不会作为消息发送给模型；持续输出时仍可处理输入和 Ctrl+C。支持退格、Ctrl+U 清空，输入最多 512 字符。会话切换、文件删除、画像管理和退出等其他命令需等本轮结束后执行。若本轮结束时尚未提交输入，已输入部分会带回下一次输入框，避免命令前缀丢失；输入过程中遇到权限确认，会先等待该行提交或 Ctrl+U 清空，再单独询问授权。

会话标题自动取首次有效用户输入的前 40 个字符，合并空白并在超长时添加省略号，无需额外请求模型。标题随会话保存，后续输入和上下文压缩不改变标题；旧会话从尚存的首条用户消息提取标题，无有效输入时显示“未命名会话”。切换会话仍使用 ID。

`/delete` 会展示目标 ID 和标题，输入 `y` 后删除对应会话 JSON 和归档 JSONL，操作不可恢复；其他输入、`Ctrl+C` 或 `Ctrl+D` 均取消。删除当前会话前，请先 `/switch` 或 `/new`；前缀不唯一时不会删除，也不支持批量删除。

新建会话或成功切换到其他会话后，需要重新确认工具授权；切回旧会话不会恢复此前授权。切换失败或切换到当前会话时，现有授权保持不变。
