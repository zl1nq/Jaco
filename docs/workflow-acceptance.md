# 任务清单与计划模式人工验收

[返回文档目录](README.md) · [工具说明](tools.md) · [交互命令](usage.md)

状态：**待人工验收**。自动化测试及构建成功不代表人工验收通过。

## 准备

使用 JDK 21，在独立测试工作目录启动本次构建的 `target/jaco.jar`（不要使用可能过期的 `release/jaco.jar`）。配置可用模型，准备可安全修改的测试文件。通过 `java -jar <项目路径>/target/jaco.jar` 启动；无需修改系统 Java 环境。

## 检查清单

- [ ] 请模型用 `todo_write` 创建 2～3 项清单。确认完整有序列表、稳定 ID、状态及完成数正确；`/todos` 立即显示且不发起模型请求。更新状态及清空数组正常。
- [ ] 退出重启后清单仍在；`/new` 使用空清单和普通模式，切回原会话恢复其清单。首次输入生成标题后清单不丢失；较长对话发生压缩后模型仍能看到最新进度。
- [ ] `/plan` 进入规划并显示 `[计划]`，重复执行展示状态和草稿；重启及切换会话后模式恢复。
- [ ] 计划阶段读取、搜索、只读 Git、归档查询、清单更新和提问正常；尝试文件修改、命令、网页抓取和子任务时被拒绝，不能出现修改预览或执行授权弹窗。
- [ ] 模型通过 `submit_plan` 提交长 Markdown 方案时能够读到完整末尾。空输入和 `a` 要求重输，只有 `y`/`n` 有效。
- [ ] 输入 `y` 后恢复普通模式并继续当前轮次；文件修改仍展示预览及独立授权，已有文件版本冲突依旧拒绝，命令仍需原有授权。
- [ ] 输入 `n` 后停止本轮，草稿和计划模式保留。补充意见后能够重新提交新版本；Ctrl+C 中断确认也不批准。
- [ ] 空闲时 `/plan cancel` 保留草稿并显示 `cancelled`，不能记录成 `approved`；运行期间不能用该命令退出规划。
- [ ] 普通模式先对某个文件或命令工具选择会话放行，再进入计划模式，仍无法使用该工具。普通问题回答及清单更新不能退出计划模式。
- [ ] 启动后台命令或子任务后尝试进入规划，提示待处理任务；取消但尚未清理结束时仍拒绝，实际退出后可进入。
- [ ] 现有文件预览、版本校验、子任务修改限制、分页与归档回读体验正常。

记录操作系统、终端类型、模型、JAR 构建时间、各项结果及异常日志。失败项需附最小复现，修复并重新验证后再由人工确认通过。
